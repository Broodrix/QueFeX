# Security notes (public claim)

QuefeX claim documentation does not ship runnable model code or weights.

When using any **private** QuefeX build obtained from Broodrix:

- Prefer brains you trained yourself.  
- Treat third-party `.qfx` / `.qhb` packages as untrusted binaries until verified.  
- There is no remote model server in the core design; threat model is local artefact loading.  

Report security issues related to distributed builds via Broodrix profile channels.
